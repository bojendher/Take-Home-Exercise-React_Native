## equipment-appraisal (Expo + TypeScript)

```bash
cd equipment-appraisal
npm install
npm start          # then press i / a / w, or scan the QR code with Expo Go
npm run typecheck
```

Navigation uses Expo Router; routes live in `equipment-appraisal/src/app/`.
